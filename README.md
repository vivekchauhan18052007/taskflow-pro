# TaskFlow Pro 🚀

A modern and responsive task management application built with React to help users organize, track, and manage their daily tasks efficiently.

## ✨ Features

* 📊 Dashboard with task overview
* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* ⏳ View pending tasks
* 🎉 View completed tasks
* 🔍 Search tasks
* 📁 Filter tasks by category
* 🚩 Filter tasks by priority
* ↕️ Sort tasks
* 📅 Manage due dates
* 📈 Task statistics
* 🏷️ Categories management
* ⚙️ Settings page
* 🌙 Dark mode
* 📱 Fully responsive design
* 🚫 Custom 404 page

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vivekchauhan18052007/taskflow-pro.git
```

### 2. Navigate to the project folder

```bash
cd taskflow-pro
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```
